# One Sentence for a Traveler from 1800

Entry for the make.fun bounty
[u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

`main.py` (pure Python standard library) writes one sentence of at most 200
characters to `/output/entry.txt`, explaining the modern internet to a time
traveler from the year 1800 using only words and things a person from 1800
would already know: a road, a library, a post office, a letter, a candle.

Run: `python3 main.py`
